# Security

## Reporting a vulnerability

Please report security issues through GitHub's private vulnerability reporting
for this repository. Do not include tokens, `.env` contents, Brainstem backups,
or other private data in a public issue.

## Backup sensitivity

RAPP Refresh snapshots may contain GitHub authentication tokens, secrets,
memories, and user-authored agents. Backups remain in the user's profile and
are never uploaded by this project. Treat the `.rapp-refresh\backups` directory
as sensitive local data.
